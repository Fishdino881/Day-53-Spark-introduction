# Day-53-Spark-introduction


###  Overview

Apache Spark is a **fast, distributed data processing framework** used for big data analytics.
It performs **in-memory computation**, making it significantly faster than traditional MapReduce.

Spark is widely used in **data engineering, data science, and machine learning pipelines**.

---

##  Why Spark?

* In-memory processing (very fast)
* Supports batch + streaming
* Easy APIs (Python, Scala, SQL)
* Works with Hadoop (HDFS, YARN)

---

##  Core Components

###  Spark Core

* Distributed execution engine
* Task scheduling & memory management

###  Spark SQL

* Structured data processing
* SQL queries & DataFrames

###  Spark Streaming

* Real-time data processing

###  MLlib

* Machine learning algorithms

###  GraphX

* Graph and network analysis

---

##  Spark vs Hadoop MapReduce

* Spark is **faster** (in-memory)
* Supports **iterative processing**
* More developer-friendly APIs
